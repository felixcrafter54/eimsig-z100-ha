# Changelog

## 0.1.1
- Meldet die Zentrale „grün“, werden auch Fenster/Türen, die seit dem Start noch nie gesendet haben,
  auf „zu“ gesetzt – sie zeigen nach der Installation also nicht mehr tagelang „unbekannt“.

## 0.1.0
- Erste Version
- Fenster/Türen (zu/gekippt/offen), Zentrale (grün/gelb/rot), Alarmanlage (scharf/unscharf), Handsender als Ereignisse
- Automatische Erkennung von Zentrale, Sensoren und Handsendern (nur Geräte, auf die die Zentrale reagiert)
- Bedeutung der Sensorcodes wird laufend von der Zentrale gelernt
- Quelle rtl_tcp; Quelle USB experimentell
